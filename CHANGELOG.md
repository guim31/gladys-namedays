# Changelog

All notable changes to this integration are documented in this file. The format
follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project
uses [semantic versioning](https://semver.org/).

Describe each change under `## [Unreleased]` as you make it. The Release
workflow moves that section under the version it ships, and the section becomes
the notes of the version's GitHub Release.

## [Unreleased]

### Added

- The name days of Germany, Austria, Poland, Sweden, Czechia, Slovakia,
  Hungary, Denmark, Finland, Estonia, Latvia and Lithuania, built into the
  integration: no account, no internet.
- A device per country: the names celebrated today and tomorrow.
- Followed names (family, friends): a device with the names celebrated today
  and the next name day, and scene triggers on the day and on the day before,
  at the hour of your choice.
- Scene actions: the names of a date in a country, and the next name day of a
  name.
- A dashboard widget: today's and tomorrow's names per country, the next name
  days of the followed names.
- Configuration actions: find a name, check the followed names.
